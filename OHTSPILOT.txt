This copy preserves upstream code and licenses. Changes on ohtspilot record
the existing device configuration, enable loggerd, and add baseline comparison
and offline stopping-sensitivity tools under tools/ohtspilot.

The ntune defaults reflect one existing device, not validated general defaults.
Existing installations read /data/ntune and /data/params; pulling this repository
alone does not synchronize those runtime settings. RecordFront=0 is captured in
the baseline to keep driver video recording disabled on the reference device.

No new longitudinal-control behavior has been deployed by this baseline.
The stopping-rate proposal remains analysis-only. Its idealized simulation is
not a Volt vehicle model or evidence of real-world safety or comfort.
Raw driving logs, videos, credentials and device identifiers are not included.

  python tools/ohtspilot/check_baseline.py

  python tools/ohtspilot/stopping_sensitivity.py
