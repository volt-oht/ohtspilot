최초 기준: a85c8436226a4371217e66de493745f0518fdfc5 + LEPRO3 실제 설정 스냅샷.
기준 기록000은 덮어쓰지 않는다. 변경은 새 번호로 추가하며 부모 번호를 기록한다.
기록할 항목: 파일 설정값, 코드 적용 후 유효값, 소스 해시, 설정 해시,
변경 이유, 검증 조건/결과, 실차 적용 여부, 원복 위치, 사용자 체감과 객관 지표.
기기 반영 전후 check_baseline.py 또는 해당 버전의 기준표로 차이를 확인한다.
실차 로그에는 설치 버전과 설정 스냅샷을 연결한다. 값이 달라진 시점이 불명확하면
같은 조건의 전후 비교라고 해석하지 않는다.

000: 기기 및 PC ohtspilot 기준 상태 대조 완료. 원본 GitHub 변경 없음.
001: 정지 감속률3.0 -> 0.9 검토. 실제 제어에는 적용하지 않음.
가정한27개 조건의 단순 모델에서 최대 약0.183m 정지거리 증가가 나왔다.
이 숫자는 실제 Volt 예측값이 아니다. 부드러움만 보고 제동을 약화시키지 않는다.

현재 기기 변경: ohtspilot 작업 브랜치 분리, 기존 수정/설정 백업,
읽기 전용 기준 대조 도구 및 기준표 추가. 가감속 제어값은 변경하지 않았다.
